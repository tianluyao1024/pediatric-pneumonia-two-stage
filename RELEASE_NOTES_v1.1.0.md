# Revision reproducibility release v1.1.0

This release aligns the public package with the final major-revision manuscript.

## Added

- Frozen Stage-1, Stage-2, matched single-stage, threshold, augmentation, inner-split and budget policies.
- Principal and conservative outer-fold assignments for all 5,281 development images.
- Blinded 120-pair near-duplicate adjudication record and method.
- Principal and conservative component-bootstrap metric tables and paired estimands.
- Source-directory technical audit with its label-permutation negative control.
- Hash-bound VinDr-PCXR/PediCXR label mapping, approval record and aggregate one-time Stage-1 result.
- Thirty fold-level runtime records covering optimizer steps, GPU time, peak memory and fixed-test reads.
- Final editable SVG/PDF figures and their numerical source data.
- Sanitized environment record and full release SHA-256 manifest.

## Scientific boundaries

- Dataset-label classification is not pathogen diagnosis.
- Filename-derived groups are not verified patient identifiers.
- The historical test directory remains fixed exploratory evidence.
- Source-directory-associated variation is not equated with hospital, device or clinical-domain shift.
- The external result is a restricted dataset-label feasibility analysis, not clinical validation.

## Excluded

Raw or derived radiographs, model checkpoints, private review keys, credentials, cookies and machine-specific absolute paths are not distributed.
