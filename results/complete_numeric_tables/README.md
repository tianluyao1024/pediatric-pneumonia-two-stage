# Complete numerical tables

These CSV files are manuscript-ready exports of the audited results. All confidence intervals are percentile 95% bootstrap intervals from 2,000 resamples of subtype-namespaced filename groups, unless a table states otherwise. The held-out test split is fixed exploratory, not confirmatory.

- `table_s1_*`: Stage 1 normal-versus-pneumonia metrics.
- `table_s2_*`: Conditional Stage 2 bacterial-versus-viral metrics.
- `table_s3_*`: whole-image development out-of-fold results.
- `table_s4_*` and `table_s5_*`: end-to-end cascade and single-stage comparator.
- `table_s6_*`: descriptive original-directory stress test.
- `table_s7_*`: paired ROC-AUC differences.
