# Protocol amendment v1.7: VinDr target-domain internal learnability analysis

## Status

Frozen before model fitting.

## Question

Can the approved 339-image VinDr clean no-finding versus pneumonia-related dataset-label subset be learned when VinDr images themselves are used for model development?

## Interpretation boundary

This is not external validation. It is a target-dataset internal, image-level cross-validation feasibility analysis. VinDr provides anonymous image identifiers but no verified patient grouping for this subset; therefore patient-independent claims are prohibited.

## Cohort and preprocessing

- 339 images: 200 clean no-finding and 139 clean pneumonia-related dataset labels.
- Use only `data_derived/lung_crop_intensity_v2/external` inputs.
- Five outer folds generated by StratifiedKFold with shuffle and seed 20260803.
- Each image receives exactly one outer-OOF prediction.
- Inner stratified validation is generated only within each outer-training partition using seed 20260803 + outer fold.

## Model

- Architecture: frozen Stage-1 EfficientNet-B0 + CBAM + GeM head.
- Initialization: ImageNet.
- Loss: BCEWithLogitsLoss.
- Optimizer: AdamW, learning rate 3e-4, weight decay 1e-4.
- Batch size: 8; maximum 12 epochs; early stopping patience 3.
- Augmentation: rotation 7 degrees; translation 4%; scale 0.95-1.05.
- Checkpoint selection: inner-validation AUROC.
- Threshold: inner-validation Youden J with closest-to-0.5 tie break.
- Final outer-fold model: fresh initialization, trained on the entire outer-training set for the selected number of epochs.

## Statistics

- Concatenate all outer-OOF predictions.
- Image-level percentile bootstrap, 5,000 replicates, seed 20260720.
- Report AUROC, AUPRC, accuracy, F1, sensitivity, specificity, PPV, NPV, and Brier score with 95% CI.

## Prohibitions

- No use of previous external probabilities to define folds, hyperparameters, or thresholds.
- No claim of independent external validation, patient-level validation, clinical diagnosis, or microbiological diagnosis.
- No comparison-driven tuning after OOF results are generated.
